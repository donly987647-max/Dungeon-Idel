## 유지하는 게임의 중심

몬스터를 영입·성장·전직시키고 파티를 파견한다. 원정은 2초 단위 행동과 누적 체력으로 진행되며, 전리품을 가공·판매해서 회사를 확장한다. 기존 계정·장비·진행 기록을 보존한다. 실제 이용자 성적을 밸런스 실험에 사용하지 않는다.

## 현재 분석 결과

운영 v0.14.2 정의의 스냅샷은 `system-baseline-v0142.json`에 보관했다. 개인 플레이 데이터는 포함하지 않는다.

- 3챕터/21아이템, 9종 표현·전직 데이터 중 영입 후보에는 6종만 등장한다.
- 바닥과 적 처치 재료가 겹친다. 바닥 드롭 표의 chance는 판정에 쓰이지 않고 균등 선택된다.
- 일반 적은 이름의 정규식과 지역 전투력으로 정해진다. 보스도 같은 공식의 배율이다.
- 500킬 후 보스가 자동 등장하고, 첫 처치 후 재등장하지 않는다. 실패하면 0킬부터 다시 요구한다.
- 기존 보스 최초 처치 타임스탬프는 있지만 화면에서 전적과 공략 판단에 활용하지 않는다.
- 실제 전투는 누적 체력·사망·회복·장비 강화·전직 스킬을 포함한다. 간단한 공격력 비교만으로 밸런스 완료를 주장할 수 없다.

## 설계 원칙

사용자가 지정한 5챕터는 **산골 마을 → 변두리 소국 → 작은 왕국 → 거대한 성 → 용사 왕국**이다. 각 챕터는 4종 적과 보스, 수집 재료 3종, 적별 전용 재료 2종, 일반 희귀 장비 8종, 보스 전설 장비 2종을 기본으로 한다. 기존 재료와 장비도 사용처와 획득처를 유지한다. 기존 3지역의 내부 ID는 저장 데이터 보존을 위해 유지한다.

보스 도전 버튼은 만들지 않는다. 일반 전투를 500회 완료하면 등장 조건이 해금되고, 이후 **전투 조우마다 1.5% 확률**로 보스가 출현한다. 승리와 패배 모두 완료 횟수에 포함하며 탐색·이동·전투 취소는 세지 않는다. 최초 해금 뒤에는 보스 승패로 진행도를 초기화하지 않는다. 과거 기록에 승리 횟수만 있어 손실된 패배 횟수를 추정해서 만들어 넣지는 않는다. 기존 해금/처치 상태는 유지한다.

보스가 주는 공통 보상은 같은 챕터의 **적 처치 표만** 합친다. 바닥 전용 재료는 보스도 주지 않는다. 재료는 제작법에 연결하며, 희귀 장비의 가치가 단순 판매 시간만으로 결정되지 않도록 전투 성능과 역할에 차이를 둔다.

기획 수치는 초깃값이다. 구현한 전투 함수를 합성 파티로 실행한 결과를 바탕으로 조정하고, 결과를 별도 보고서에 남긴 후 배포한다.

- 5챕터 커버 아트를 내장 이미지 생성 도구로 만들고 `assets/art-v015/`에 저장했다. 정확한 프롬프트와 원본 경로는 같은 디렉터리의 README에 기록했다.
- 챕터 카드, 적 스킬·전리품 도감, 보스 최초/최근 처치와 승패 이력, 파티 편성·대응력 평가를 연결했다. 버튼을 누르는 보스 소환 흐름은 없다.
- 다음 업무는 영입, 전리품 수거, 제작·정산·완제품 판매, 부상자와 전직 한도 도달에 따라 안내한다. 출동 중 전직 한도에 도달한 직원도 복귀 안내를 받는다.
- 파티 선택은 초점과 스크롤을 유지한다. 열려 있는 보스 전적과 현재 파티의 부상 정보는 상태 갱신을 반영한다.
- 360·390·768·1280px 합성 브라우저 검사를 통과했고 캡처를 확인했다. 기존 누적 HP·전멸·원정 재편 UI 회귀도 360·390·430·768·1024px에서 통과했다.
- 준비/미준비 조건별 30회, 총 300회 실제 SQL 전투와 화면의 대응력 계산을 비교했다. 이번 표본의 안정권 5조건은 모두 30/30 승리했다. 확률적 추정이며 모든 조합에 대한 보장은 아니다.
- 장비 없는 B등급 골렘·만드라고라·임프가 실제 전투를 연속 수행하는 1개 시드에서 5챕터를 통과했다. 사망자가 생기거나 전직이 가능할 때 복귀했다. 첫 보스 조우는 일반 전투 669/675/507/509/535회 후였다. 조작 지연 없는 2초 행동 시간 합계는 약 13.3시간이다. 전투 성장 경로를 확인한 결과이며, 제작·판매·시설 투자를 포함한 전체 경제 검증은 아니다.

### 전리품·장비·적 아트 개선

- 적 20종과 보스 5종의 픽셀 아틀라스를 도감과 전투 화면에 연결했다. 전투 장면도 해당 챕터의 커버 배경을 사용하고 OP-001~005 코드로 구분한다.
- 전설 장비 10종과 대표 재료/장비 6종의 새 아이콘을 추가했다. 생성 파일과 프롬프트는 `assets/art-v015/README.md`에 기록했다.
- 강화 수치, 기존 장비, 몬스터 성격, 치명/회피 상한을 반영한 실제 능력치 증감을 장착 전에 표시한다. 테스트에서는 +10 몽둥이를 교체할 때 공격 -11과 전설 +3 장비의 공격 +4를 확인했다.
- 서버가 실제 지급한 아이템 이름과 등급을 전투 로그 및 수거 결과에 표시한다. 장비는 접힌 전투 기록 밖에도 보관 중 배너로 표시하며 수거하면 사라진다.
- 현장 재료 3,000개 한도와 별도로 장비를 보관한다. 재료 만재 상태의 전설 지급·수거·중복 방지, 실제 획득하지 못한 바닥 재료의 로그 0개 표시를 실제 SQL 검사에 추가했다. 서버 검사 18개 통과.
- 모바일 장비 비교, 득템, 새 적 렌더링과 교체 화면 캡처를 확인했다. 기존 원정 UI 회귀 검사도 통과했다.

### 경제 통합 검증

제작법 시설 조건을 서버와 UI에서 강제하고, 시설 확장은 원자적 함수와 예상 레벨로 중복 클릭을 방지한다. 창고 종류별 용량을 실제 수거·완제품 수령에 적용하며, 공간 부족 때 전리품과 완제품을 보존한다. 필요한 신규 슬롯까지 계산해 확장을 안내한다.

26개 제작법의 실제 재료 차감 → 일괄 제작 → 수령 → 판매 → 정산, 중복/조기 수령 거부, 소유권, 창고 포화, 자동 수령, 시설 결제 검사를 통과했다. 실제 초기 회사 생성과 슬라임·무료 후보 영입부터 시작한 연속 실험은 5챕터를 통과했다. 수익으로 숙소 2, 창고 2, 공방 3을 확장했으며 창고로 막힌 수거 0회였다. 마지막 보스는 4패 후 승리했다. 장비 미착용, 적극적인 재정비, 단일 시드의 합성 실험이므로 모든 파티나 오프라인 플레이의 보장치는 아니다.
