# v0.16.1 — 계정 초기화와 운영 방침 제거

사용자 요청에 따라 모든 회사의 진행을 신규 상태로 초기화한다. 로그인 계정과 PIN은 유지한다. 기존 장비·강화 장비·재료·재화·시설·원정·보스 전적·제작 및 판매 작업·던전 방어 진행은 제거하고, 각 회사에 Lv.1 시작 직원과 무료 영입 후보 3명을 다시 제공한다.

운영 방침 화면, API, 설정 컬럼과 자동 제작/판매 시작·전리품 운송·시설 투자·장비 교체·챕터 이동 로직을 제거했다. 출정한 작전의 자동 전투·회복·재출정, 예약한 전직, 직접 시작한 제작/판매의 완료 처리는 유지한다.

초기화 SQL은 `tools/reset-all-game-progress.sql`의 일회성 운영 작업이다. 배포 마이그레이션에 포함하지 않아 이후 배포 시 재초기화되지 않는다. 게임 처리와 같은 advisory lock을 잡고 하나의 트랜잭션에서 삭제와 재생성을 수행한다. 플레이어 FK가 없는 구형 강화 인벤토리도 명시적으로 초기화한다.

검증: 실제 SQL로 자동 의사결정 제거, 직접 예약한 제작 완료, 보스 처치 후 현재 챕터 유지, 로그인 정보 보존 및 모든 진행 테이블 초기화를 확인한다. UI 회귀 검사 6개와 TypeScript 검사 통과. 기존 서버 검사 42개는 이전 마이그레이션의 회귀를 검사하고, `manual-operations.test.mjs`가 최신 변경을 적용해 검증한다.

운영 적용 결과: 저장된 회사 5개 전부 초기화, 로그인 계정 3개 보존. 시작 직원 5명·영입 후보 15명, 재고·강화 재고·장착 장비·원정·챕터 기록·제작/판매 작업 0건을 확인했다. 시설/재화는 기본값, 방어 진행은 0이다. 운영 방침 RPC 및 설정 컬럼은 존재하지 않는다. Edge API v14에 정책 액션 제거를 배포했다.
