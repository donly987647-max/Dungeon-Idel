# v0.16 방치형 회사 개편

사용자 요청 1–8의 구현 범위다. 기존 개인 자산·보유 장비·직원 ID·전직 기록을 보존한다. 신규 회사만 0G. 실험은 합성 계정으로 진행한다. 실제 결과와 배포 증거는 [검증 기록](idle-v016-verification.md)에 정리한다.

## 구현 기준

- 신규 금고 0G, 무료 초기 지원. 기존 회사의 잔액을 일괄 초기화하지 않는다.
- 전투불능은 원정 행동 12회(기본 24초) 후 부활. 전멸은 15행동(30초) 재정비 후 같은 원정 자동 재개. 수동 복귀/재편으로 회복 대기를 건너뛰지 못한다. 사망 XP 삭감 폐지.
- 자동 운송·상품 가공·판매·완료 수령·정산. 제작용 희소 재료와 장비는 자동 판매하지 않는다. 자동운영은 서버 시각으로 진행하여 접속 빈도와 무관하다.
- 자동 전직 예약과 근속 승급(C→B→A→S). 높은 시작등급은 초반 이점, 낮은 시작등급도 장기근속으로 성장. 승급과 전직의 다음 조건 및 고유 스킬을 표시한다.
- 챕터별 18개 현역 장비: 무기/방어구/장신구 각각 일반 1, 희귀 2, 영웅 2, 전설 1. 총 90개. 일반은 일반 적 저확률 드롭, 희귀/영웅은 챕터 희소 재료+공통 재료 제작. 전설은 보스 전용. 이전 장비는 보존하고 이전 세대 표기로 구분한다.
- 제작소·상점 첫 화면은 진행 작업과 추가 버튼. 추가 화면에는 검색/챕터/등급/부위/제작 가능 필터. 완료 수령은 자동.
- NEW/새 소식은 시설명 옆의 선명한 배지와 본부 상단 알림 영역. 키보드/모바일 가독성과 알림 확인 동작 검증.
- 몬스터 9계열의 회사 테마 디자인, 고유 스킬, 2단계 분기 진화 재구성. 기존 계열/형태 ID는 유지. 기본 움직임·타격·피격·회복·부활 애니메이션, reduced-motion 지원.

## 완료 증거

각 요구에 대해 실제 SQL 회귀 검사, 경제·장비 획득경로·제작시간·소유권·중복처리 검사, 두 시드의 수동/방치 진행 비교, 360/390/768/1280 화면과 흐름을 검증했다. GitHub 검사, 운영 DB 함수/콘텐츠, Edge API, Vercel 배포 원본 일치와 동작까지 확인했다. 코드·콘텐츠·화면은 운영에 적용했으며, 검증 기록에 결과와 범위·한계를 구분했다.

## 추가 요청 8 — 던전방어

박멸 옆에 던전방어 탭. 탐험 미출정 직원 자동 배치, 용사는 반격 없이 마왕방으로 이동하며 도착 전 처치 실패 시 보상 없음. 진화 단계·등급·레벨에 비례하는 공격, XP 없음, 탐험보다 낮은 드롭률. 단계 선택, 반복 웨이브, 보스 연속 도전(실패 즉시 OFF 및 직전 단계 반복), 골드 시설(함정·독가스·둔화·마력 장치), 서버 판정과 실시간 이동/공격 애니메이션. 소유권·보상 중복·실패 전환·파견중 제외·단계 이동·강화 비용과 화면 동작을 검사했다.
