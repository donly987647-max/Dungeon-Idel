# v0.15 서버 개편 검증 기록

현재 상태: v0.15 운영 배포 및 검증 완료. 아래 합성 실험 조건과 한계를 함께 읽는다.

## 콘텐츠와 서버 동작

사용자가 지정한 순서는 산골 마을 → 변두리 소국 → 작은 왕국 → 거대한 성 → 용사 왕국이다. 기존 3지역 ID와 기존 아이템 ID를 유지한 채 5챕터, 일반 적 20종, 보스 5종, 아이템 106종, 제작법 26종을 구성했다. 전설 장비는 보스마다 2종씩 총 10종이다.

일반 적마다 재료 2종과 장비 2종의 개별 표가 있다. 각 장비 확률은 0.2%다. 보스는 같은 챕터의 적 보상만 공유하고, 전설은 한 번의 추첨에서 총 1.5%, 각각 0.75%로 등장한다. 약탈 보너스는 최대 20%까지 곱해지며, 보스 등장 확률에는 영향을 주지 않는다. 바닥 전용 재료는 적과 보스에게서 나오지 않는다.

보스는 일반 전투 500회 완료로 해금되고 이후 **적과 조우할 때 1.5% 확률**로 자동 등장한다. 완료된 일반전 승리·패배를 모두 세며, 단순 조우나 취소는 세지 않는다. 보스를 처치하거나 패배해도 해금은 유지한다. 수동 도전 RPC와 버튼은 새 설계에 없다.

## 실제 PostgreSQL 함수 검사

`npm test --prefix tools/simulation`은 운영 스키마·함수·트리거·인덱스를 PGlite에 복원하고 개발 중인 마이그레이션을 적용한다. 모든 파티는 합성 데이터다.

검사 범위:

- 지정한 챕터 순서와 콘텐츠 수, 기존 아이템 ID·클리어 기록 보존
- 모든 재료의 제작 사용처, 기존 제작법까지 포함한 재료 가치와 판매가 비교
- 30,000회 바닥 추첨에서 45/35/20 선택 가중치 확인
- 60,000회 보스 보상 추첨에서 전설별 확률 확인, 한 번에 전설 최대 1개
- 모든 일반 적의 실제 드롭 결과에 바닥/보스 전용 물품이 없음을 확인
- 100,000회 해금 후 보스 추첨에서 1.5% 빈도, 해금 전 0%
- 500전투 해금, 자동 조우 시 실제 보스 프로필, 처치 후 반복 조우
- 최초/최근 처치·승패 기록, 패배 시 해금 보존, 사망한 아군 XP 제외
- 적의 정해진 턴 회복 스킬과 로그, 일반전 패배의 완료 횟수 반영
- 내부 보상 함수 권한, 신규 회사 생성 원자성과 재호출 안전성
- 9종 영입 가능성, 후보 잠금 유지, 후보 능력치/성격과 영입 결과 일치

## 보스 전투 초기 비교

명령: `BALANCE_SAMPLES=30 node tools/simulation/balance.mjs`.
총 300회, 각 조건당 30회의 실제 전투 함수를 실행했다. 표의 승률은 이 작은 합성 표본의 결과이며 보장 확률이나 플레이어 화면에 표시할 승률이 아니다.

| 챕터 | 준비 부족 레벨 / 승률 | 준비된 레벨 / 승률 |
|---|---:|---:|
| 산골 마을 | Lv.1 / 50.0% | Lv.6 / 100% |
| 변두리 소국 | Lv.6 / 26.7% | Lv.14 / 100% |
| 작은 왕국 | Lv.18 / 16.7% | Lv.26 / 100% |
| 거대한 성 | Lv.31 / 63.3% | Lv.39 / 100% |
| 용사 왕국 | Lv.47 / 46.7% | Lv.55 / 100% |

공통 조건은 성장 B, 학습 본능, 침착, 최대 HP 시작이다. 첫 두 챕터는 골렘·만드라고라·임프, 이후 고블린을 추가한다. 가능한 전직을 실제 전직 함수로 수행한다. 준비 부족은 무장 없음, 준비된 파티는 이전 챕터의 일반 장비 1개씩 +3 강화다. 첫 챕터는 양쪽 모두 장비가 없다. 전설 장비나 전체 슬롯 완벽 장비는 가정하지 않았다.

## 경제·연속 진행·화면 검증

서버 콘텐츠/전투 검사 18개와 경제 검사 6개가 통과했다. 경제 검사는 모든 26개 제작법을 실제 함수로 제작·수령·판매·정산한다. 조기·중복 수령, 타인 작업 수령, 잔액 부족과 오래된 시설 레벨 요청, 창고 포화 시 수령 보류를 확인했다. 자동 처리도 창고가 가득 찬 한 계정 때문에 전체 처리를 중단하지 않는다.

실제 시작 슬라임, 무료 만드라고라·임프, 판매 수익으로 숙소 확장 후 골렘 영입으로 시작한 연속 실험 결과다. 장비를 착용하지 않았으며 전직·사상자 발생 때 복귀했다. 작업 시간은 행동당 2초씩 경과시키고 실제 SQL 함수가 생산·정산한다.

| 챕터 | 첫 보스까지 일반 전투 | 보스 승/패 | 행동 시간 |
|---|---:|---:|---:|
| 산골 마을 | 524 | 1/0 | 114.6분 |
| 변두리 소국 | 584 | 1/0 | 150.4분 |
| 작은 왕국 | 539 | 1/0 | 149.4분 |
| 거대한 성 | 543 | 1/0 | 178.6분 |
| 용사 왕국 | 506 | 1/4 | 205.9분 |

합성 수익은 누적 17,349G, 시설 비용 8,500G, 최종 금고 9,529G(시작 680G 포함). 숙소 2·창고 2·공방 3에 도달했고 수거 용량 실패는 0회였다. 원본은 `campaign-v015-progression-sample.json`, 경제 검사는 `campaign-v015-economy-checks.json`에 있다. 단일 시드 및 적극적인 조작을 가정하며 사용자 조작 지연, 전체 파티 조합, 오프라인 스케줄링을 대표하지 않는다.

모바일/데스크톱 360·390·768·1280px에서 챕터 순서, 안내, 도감, 전적 갱신, 파티 편성, 초점 유지, 아트 로딩·교체, 전설 보관 배너, 강화 반영 장비 비교, 제작 시설 조건과 창고 확장 안내를 확인했다. 기존 누적 HP·전멸·원정 재편 회귀도 별도 검증했다. 캡처는 로컬 `tools/simulation/results/ui`에 남긴다.
