# v0.16 방치형 회사 검증

## 구현과 보존

- 새 회사 0G. 기존 금고·직원 ID·보유 장비·강화·챕터 전적 보존.
- 쓰러진 직원은 원정 12행동, 전멸 파티는 15행동 후 자동 복귀. 사망 XP 차감 없음.
- 서버가 30초마다 운송, 회사 상품 제작·판매, 완료 처리, 필요 제작소·창고 확장.
  희소 재료와 장비는 자동 판매 대상에서 제외. 수동 예약을 먼저 처리한다.
- 전투 사이 자동 장착·전직, 전투 완료마다 근속 1점. 200/800/2,000점 승급.
- 5챕터 × 3부위 × (일반 1+희귀 2+영웅 2+전설 1)=90개 현역 장비.
  희귀/영웅 제작법 60개, 기존 회사 상품 제작법 26개. 기존 장비는 이전 세대로 보존.
- 일반 드롭 부위별 0.3%, 희귀 촉매 0.15%, 영웅 촉매 0.05%, 보스 전설 부위별 0.1%.
  희귀는 촉매 1개와 30~60분, 영웅은 촉매 2개와 3~5시간 제작. 한 보스에서 전설 최대 1개.
- 회사 보직 테마 9계열, 스킬 65개·전직 경로 56개, 3단계 투명 아틀라스.
  기존 모든 분기 ID와 직원의 성장 기록은 유지한다.
- 본부 NEW를 제목 옆과 알림 영역에 표시. 제작소·상점은 작업부터 표시하고 별도 목록·필터 제공.
- 별도 던전방어: 미출정 직원의 레벨·등급·진화로 화력 계산, 반격·XP 없음.
  50단계, 보스 연속 도전과 실패 시 OFF, 이전 단계 반복, 네 가지 골드 설비.
  설비는 각 레벨마다 1.28배로 비용 증가하며 최대 레벨은 25다.
  방어 웨이브 보상은 탐험 표의 25% 확률, 전설은 보스 전용. 창고 포화 보상은 별도 보관.

## 자동 검사

실제 PostgreSQL 함수와 스키마를 PGlite에 복원해 합성 계정으로 검사한다.
기존 전투·경제 24개, v0.16 부활·장비·자동운영 10개, 던전방어 8개로 총 42개를 통과했다.
모든 60개 장비 제작법의 재료·수량·시간·중복 지급을 검사했다.
50단계 보스는 최대 육성 직원 11명과 최대 설비로 돌파 가능하다.
방어 확률은 실제 80,000회 추첨으로 표본 확인하고 전설 동시 지급과 일반 적 전설을 배제한다.

브라우저 합성 API 검사 6개 흐름은 360/390/768/1280px에서 다음을 확인한다.
NEW 위치와 확인, 대기열 우선 화면, 필터 교집합과 검색 초점 유지, 수량 예약,
전직 경로 예약과 열어 둔 승급 정보 갱신, 운영 토글, 방어 이동·단계·실패·강화,
전투 타격·피격·회복, 아트 로딩, 모션 감소 설정을 확인했다.
같은 검사를 공개 운영 프런트엔드에서도 통과했다. 기존 원정 재편·누적 HP 회귀도 통과했다.

`deno check`와 전체 프런트엔드 구문 검사, 생성 마이그레이션 원본 일치를 별도로 확인한다.
로그인용 Supabase 클라이언트를 분리하여 플레이어 세션이 공용 서비스 권한을 대체하지 않게 했다.
시간 진행 RPC는 클라이언트에서 직접 호출할 수 없고 서버만 실행한다.

## 장시간 진행 실험

`tools/simulation/idle-progression.mjs`는 0G, 기본 슬라임, 무료 회복 담당·임프를 출정시키고
실제 전투·부상·스킬·성장·전직·장비 드롭·운송·제작·판매·시설 결제를 연속 실행한다.
행동당 2초를 진행하며 강제 승리·강제 보스·XP/장비 지급·수동 복귀는 없다.
방치 모드와 매 행동마다 운송·완료·전투 사이 장착을 수행하는 빈번한 조작 모드를 비교한다.
이는 접속·수거 빈도의 차이를 평가하며, 가능한 모든 파티·수동 제작 최적화를 대표하지 않는다.

각 회사 24,000행동, 게임 시간 13시간 20분을 동일하게 진행한 결과다.
[두 시드의 원본 결과와 코드 해시](idle-v016-progression-samples.json)를 함께 보관한다.

| 시드 | 방식 | 승리 | 총 판매 수입 | 5챕터 완료 확인 행동 |
|---|---|---:|---:|---:|
| 0.217 | 방치 | 3,471 | 20,568G | 19,000 |
| 0.217 | 빈번한 수거·정산 | 3,460 | 20,103G | 18,500 |
| 0.641 | 방치 | 3,410 | 19,885G | 20,000 |
| 0.641 | 빈번한 수거·정산 | 3,453 | 19,245G | 20,000 |

전투 수 차이는 시드별 0.32%·1.25%, 총 판매 수입 차이는 2.31%·3.33%다.
차이는 `두 방식의 절대 차이 / 빈번한 수거·정산 값`으로 계산했다.
네 회사 모두 5챕터 완료, 직원 3명 전원 S·Lv.60·최종 전직에 도달했으며 패배는 없었다.
제작소 Lv.3·창고 Lv.1, 직원당 5챕터 일반 장비 3부위 자동 장착 상태로 끝났다.
시설 투자 후 잔액과 누적 총 판매 수입은 구별한다. 후자가 비교 지표다.
챕터 완료는 500행동마다 확인했으므로 정확한 완료 시각에는 최대 16분 40초의 확인 간격이 있다.

두 시드와 이 파티를 대상으로 한 표본이며 모든 파티·전직 선택·수동 강화·장비 제작 전략의
최대 효율을 보장하지 않는다. 장시간 실행의 PGlite 행 버전 누적은 쿼리 사이 VACUUM으로
정리했다. 전투·경과 시간·보상·난수 상태를 직접 수정하거나 승리를 주입하지 않았다.
